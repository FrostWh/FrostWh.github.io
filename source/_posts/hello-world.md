欢迎使用 Hexo！这是你的第一篇文章。如果你在使用过程中遇到任何问题，可以查看 [文档](https://hexo.io/docs/) 或在 [GitHub](https://github.com/hexojs/hexo/issues) 上提问。

## 快速开始

### 创建新文章

```bash
$ hexo new "我的新文章"
```

### 启动服务器

```bash
$ hexo server
```

### 生成静态文件

```bash
$ hexo generate
```

### 部署到远程站点

```bash
$ hexo deploy
```

更多信息请查看 [部署文档](https://hexo.io/docs/one-command-deployment.html)。
